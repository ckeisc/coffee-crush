# Coffee Crush

A three.js coffee-shop match-3 game, built with Muse.

- 8×8 board, 6 base treats (Coffee Bean, Sugar Cube, Croissant, Donut, Cherries, Cupcake)
- 2 specials: match-4 Espresso Blast clears a row + column, match-5 Golden Bean Bomb clears all of the swapped kind
- Orders: three trays above the board, 20 pre-programmed orders per level across 5 levels — clear all 20 before moves run out
- Strictly top-down camera, swipe-only input (no tap-to-select), no gem drop shadows
- Synthesized pop/blast/win sounds, 2D fallback if WebGL is unavailable

Play it live: https://ckeisc.github.io/coffee-crush/

Static site — just open `index.html` (or serve the folder); no build step.
